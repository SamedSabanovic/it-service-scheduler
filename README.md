# it-service-scheduler
Simulation of an IT Service ticketing system using SJF, SRTF, and Priority scheduling algorithms in Python.

## Opis projekta
Ovaj projekat simulira rad IT servisa kroz primjenu tri ključna algoritma operativnih sistema:
* **SJF (Shortest Job First)** - Non-preemptive obrada najkraćih kvarova.
* **SRTF (Shortest Remaining Time First)** - Preemptive prekidanje rada u korist hitnijih popravki.
* **Priority Scheduling** - Raspoređivanje na osnovu važnosti klijenta (Serveri, Biznis, Privatni korisnici).
